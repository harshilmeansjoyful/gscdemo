The README.md file:
Extract the Files: Unzip the downloaded project to a local directory.

Open in VS Code: Open the extracted folder in Visual Studio Code.

Install Dependencies: Run npm install in the terminal to install all required dependencies.

Start the Application: Run npm run dev to start both the backend and frontend servers.

Access the Application: The application will be available at http://localhost:5000.

Login: Use the provided sample credentials to log in as different user roles.
